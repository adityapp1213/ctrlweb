# Community environment assets

The original files are unmodified. Menagerie ALOHA supplies the textured table meshes and collision dimensions; Menagerie Panda supplies the calibration block. Robosuite supplies textured can/lemon meshes, the sorting bin, and the ball/controller references. Original licenses are included in their source folders.

The application assembles these components, configures table dimensions and placement for each robot, and tunes native MuJoCo contact parameters. It does not rescale robot models or replace their actuator definitions.
